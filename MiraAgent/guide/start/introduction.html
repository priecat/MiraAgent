    #内核适用场景

    #功能特性

    • 基于纯JVM环境运行，最低兼容JDK 8，可在存量业务项目中以较低改造成本快速接入智能体能力。
    • 用于快速搭建轻量便携的智能体应用，支持少量代码即可完成原型验证，开展业务场景可行性预研。
    • 支持运行态快照输出、跨进程中断恢复，适配远端服务、容器、沙箱、虚拟机等部署环境，实现毫秒级冷启动任务复原。
    • 无需引入 Spring AI、LangChain4j 等重型框架，即可开箱获得多轮对话、流式输出、工具调用循环、会话记忆等完整能力。
    • 对话业务逻辑与模型网关、存储实现解耦，支持多套配置切换与共存，方便开展各类业务场景的定制化开发。
    • 支持单进程内多套运行时隔离，满足多用户、多租户、多环境的并发使用。

    模型网关接入、存储与鉴权、部署与运维、UI 呈现、编排主循环与调度，均由业务方实现（见边界）。

    #核心能力

    能力内核提供若基于大模型 API 自行实现
    流式输出将 SSE 分片解析为事件流（思考、正文、结束、报错），按序推给应用自行解析分片、拼接正文与思考、判断结束
    工具调用循环解析模型下发的工具调用、执行、回填结果、进入下一轮，循环由内核驱动自行实现解析、执行、回填与循环控制
    会话文件读写提供会话附件包（VFS）与工作空间两套文件读写自行管理目录、路径与附件包
    历史与回放预留持久化扩展点，消息与过程事件可按时间线存取自行设计消息表与事件表，并编写存取逻辑
    模型切换按别名查找、切换模型，与具体网关解耦自行维护别名到网关的映射
    多租户隔离一个进程内可运行多套互不干扰的运行时自行做隔离

    #边界

    内核提供需由调用方提供
    对话循环、流式事件化、工具调用循环模型网关的接入与密钥管理
    会话附件包与工作空间的读写持久化存储介质（MySQL / Redis / 文件等）及其实现
    配置快照的导出与导入用户体系、登录与权限
    按别名查找、切换模型部署、扩容与运维
    执行前预校验（模型 / 工具 / 必需参数）UI 与前端呈现方式
    （编排时）单节点的装配、校验、执行编排主循环、分支、并发调度与状态恢复

    #典型用法

    用法做法内核承担的部分
    从零搭建 AI 应用用内核承载一个有对话、会调用工具的助手对话与工具循环、流式、记忆的全部运行逻辑
    给已有系统加 AI 入口把内核装配进现有服务，新增一个对话接口对话执行与工具循环；接口与现有系统的集成由业务负责
    做流程编排执行器多个 AI 步骤按图依次执行每步的模型校验、工具解析、执行与事件；主循环与调度需自行实现（见编排：让 AI 按流程跑）
