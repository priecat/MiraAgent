# Mira Agent Core


轻量级 Java AI Agent 内核，不依赖 SpringAI / LangChain4j 等AI框架。上层可将其作为库嵌入业务系统，也可作为编排运行时驱动多步骤工作流。




</div>


## 快速开始

完整用法、API 与扩展说明见  [参考文档](https://mira.itzq.net/MiraAgent/)  

## 特性 & 适用场景

- 基于纯JVM环境运行，最低兼容JDK 8，可在存量业务项目中以较低改造成本快速接入智能体能力。
- 用于快速搭建轻量便携的智能体应用，支持少量代码即可完成原型验证，开展业务场景可行性预研。
- 支持运行态快照输出、跨进程中断恢复，适配远端服务、容器、沙箱、虚拟机等部署环境，实现毫秒级冷启动任务复原。
- 无需引入 Spring AI、LangChain4j 等重型框架，即可开箱获得多轮对话、流式输出、工具调用循环、会话记忆等完整能力。
- 对话业务逻辑与模型网关、存储实现解耦，支持多套配置切换与共存，方便开展各类业务场景的定制化开发。
- 支持单进程内多套运行时隔离，满足多用户、多租户、多环境的并发使用。


 
 
## 核心能力

| 能力 | 内核提供 |
|---|---|
| 流式输出 | 将模型 SSE 分片解析为事件流（思考、正文、结束、报错），按序推给应用 |
| 工具调用循环 | 解析模型下发的工具调用、执行、回填结果、进入下一轮，循环由内核驱动 |
| 会话文件读写 | 提供会话附件包与工作空间文件读写 |
| 历史与回放 | 预留持久化扩展点，消息与过程事件可按时间线存取 |
| 模型切换 | 按别名查找、切换模型，与具体网关解耦 |
| 多租户隔离 | 一个进程内可运行多套互不干扰的运行时 |


## 环境依赖

运行环境：JDK8

内核的运行时依赖如下：

| 依赖 | 版本 | 用途 |
|---|---|---|
| freemarker | 2.3.35 | 提示词模板渲染 |
| transmittable-thread-local | 2.14.5 | 跨线程上下文传递 |
| jackson-core / databind / annotations / datatype-jsr310 | 2.15.2 | JSON 序列化 |
| slf4j-api | 1.7.32 | 日志 |
| hutool-http | 5.8.46 | HTTP 客户端 |

Lombok 仅在编译期使用（`provided`）；JUnit 4 只用于测试（`test`）。
